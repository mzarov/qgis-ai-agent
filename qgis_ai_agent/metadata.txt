about=The agent inspects the open project, styles layers, runs Processing, edits data and creates layouts from plain-language requests. Changes wait in a visible plan until you press Apply. THE FIRST AGENT RUN AGAINST A REMOTE ENDPOINT WAITS FOR PER-ENDPOINT CONSENT. The explicit Test connection action sends one short diagnostic request independently of agent-run consent. Sent data can include prompts, recent chat, project notes, basic layer and field metadata, and tool results. Sensitive GIS data and tool results—feature attribute values; exact map and layer extents; layer filters and sources; style categories; Processing and Python results; and rendered map or layout images—require a second option that is off by default. Conversation messages and project notes are stored as plain JSON in the QGIS profile. API keys are stored in the system keychain. EXTERNAL PYTHON DEPENDENCY: keyring is not bundled and may need to be installed into the Python used by QGIS; see Setup. OpenAI-compatible, Anthropic and local endpoints are supported. A local server can still store or forward data. The interface is available in English and Russian.
