about=The agent inspects your project on its own — layers, attribute fields, CRS, styling — then styles layers, runs Processing algorithms and downloads OpenStreetMap data from a description in plain language. Read-only actions run immediately; anything that changes the project is collected into a plan and applied only after you press Apply. REQUIRES AN ACCOUNT AND API KEY with a language-model provider: the plugin works with any OpenAI-compatible endpoint and with Anthropic, including local servers such as Ollama or LM Studio (no key needed for localhost). Your prompts and short summaries of the project — layer names, field names, CRS — are sent to the provider you configure, so pick one you trust. The key is stored in your system keyring, never in the project or settings file. The interface is available in English and Russian, following the QGIS interface language.
