# Security policy

Please report vulnerabilities privately to `mzarov@duck.com`. Do not open a
public issue containing an API key, a private endpoint, client data, project
files, credentials, or an exploit that puts users at immediate risk.

Include the plugin and QGIS versions, operating system, impact, safe reproduction
steps and any suggested mitigation. Redact provider responses and local paths.
You should receive an acknowledgement within seven days.

Security fixes are made for the latest published version. Until the first stable
release, all versions are experimental and users should update to the newest
available build.
