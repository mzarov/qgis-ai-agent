# Smoke Checklist

Ручная проверка в живом QGIS. Автотестов в проекте нет.

## Техническая проверка после правок

- `python3 -m compileall -q src/` — должно пройти без ошибок.

## Регресс дипломного поведения (тег `v0.1.0-diploma`)

Композиция макета не менялась, поэтому эти сценарии должны работать как раньше.

- `A4 portrait` (210x297): «создай макет A4 с картой, легендой, заголовком и линейкой»
- `A4 landscape` (297x210): тот же запрос
- `A3 landscape` (420x297): тот же запрос

Ожидания:

- `title/top-center` — для `role=title` принудительно применяется top-center
- `text-stability` — `add_label` чистит невидимые символы (`Cf/Cc`, ZWSP, BOM, NBSP)
- `bounds` — `clamp_to_page_bounds` не даёт элементам уйти за страницу
- `anti-overlap` — единый `place_item_with_policy` для map/legend/label/scalebar
- `scalebar-readability` — деления и длина подбираются автоматически
- `existing-layout-reuse` — правки применяются к существующему макету без `create_layout`
- `missing-map-error` — `add_scale_bar` без карты даёт понятную ошибку

## Агентный цикл

- **Чтение без подтверждения.** «что у меня в проекте?» → агент вызывает
  `list_layers` / `list_layouts`, отвечает по факту, кнопки подтверждения не
  появляются.
- **Данные из проекта.** «какие поля в слое X?» → `describe_layer`, в ответе
  реальные поля, а не выдумка.
- **Смешанный сценарий.** «посмотри слои и собери макет по самому подробному» →
  read-тулы отработали сразу, write-ы пришли батчем на подтверждение.
- **Отмена.** Нажать «Отмена» → в проекте ничего не изменилось.
- **Ошибка тула не рвёт прогон.** Попросить макет с несуществующим слоем →
  агент видит ошибку и исправляется сам, а не падает.
- **Лимит ходов.** Заведомо неподъёмная задача → прогон останавливается на
  `MAX_ITERATIONS` с внятным сообщением, QGIS не виснет.

## Скиллы

- Простой вопрос про слои не требует `load_skill` — `inspect` предзагружен.
- Запрос про макет → в логе `QGIS AI Agent` видно `Загружен скилл: layout`.
- Запрос про обработку → `Загружен скилл: processing`.
- Скилл загружается один раз за прогон, повторных загрузок в логе нет.

## Обработка данных

- «найди алгоритм буфера» → `search_processing` возвращает `native:buffer`.
- «построй буфер 500 м вокруг дорог» → цепочка search → describe → run,
  запуск попадает в батч на подтверждение, результат появляется в проекте.
- Слой в географической CRS → агент предупреждает про метры, а не молча считает.

## Транспорт

- **Эндпоинт с function calling** — работает нативный путь.
- **Эндпоинт без него** — первый запрос падает на `tools`, адаптер уходит в
  JSON-протокол, флаг `supports_tools` записывается, следующие запросы сразу
  идут по JSON-пути.
- Смена URL в настройках не ломает выбор: флаг хранится по хешу URL.

## Потоки и выгрузка

- UI не подвисает во время многошагового прогона.
- Выгрузка плагина при активном запросе не роняет QGIS.
