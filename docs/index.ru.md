# AI Agent

AI Agent — плагин для QGIS 4, который работает с вашим проектом по запросам на
обычном языке. Он читает проект, вызывает инструменты, смотрит на результат и
решает, что делать дальше. Изменения ждут в плане, пока вы не нажмёте
**Применить**.

## Что умеет

Девятнадцать доменов, 90 инструментов:

| Домен | Пример запроса |
| --- | --- |
| `inspect` | какие у меня слои? |
| `project` | добавь подложку OSM |
| `style` | раскрась районы по населению |
| `processing` | построй буфер 500 м вокруг школ |
| `osm` | скачай кафе в Твери |
| `data` | найди безоблачный снимок Sentinel-2 этого района |
| `draw` | поставь точку 55.75, 37.62 |
| `edit` | удали выделенные объекты |
| `fields` | добавь виртуальное поле с площадью в гектарах |
| `layout` | собери лист А4 с легендой и экспортируй в PDF |
| `python` | выполняет сниппет PyQGIS, который вы сначала читаете и одобряете |
| `web` | прочитай эту страницу документации |
| `annotations` | добавь заметку на карту |
| `three_d` | открой 3D-вид этого проекта |
| `tables` | присоедини этот CSV к районам по коду |
| `sql` | сколько школ в каждом районе? |
| `charts` | диаграмма населения по районам |
| `plugins` | какой плагин сделает веб-карту? |
| `quality` | проверь мои данные на ошибки |

На модели, которая принимает изображения, агент ещё и смотрит на отрисованную
карту. После нажатия «Применить» он проверяет результат и предлагает
исправления, если что-то не получилось.

## Как применяются изменения

- Инструменты, которые только читают проект, выполняются сразу.
- Инструменты, которые меняют проект, ждут в карточке плана, пока вы не
  нажмёте **Применить**. **Отменить** сбрасывает весь план.
- Инструменты, которые обращаются к веб-сервису, спрашивают перед каждым
  вызовом.
- Шаги, которые правят или удаляют данные на месте, выполняют Python или
  код другого плагина, спрашивают ещё раз.

В режиме «Авто» план применяется сам, если в нём нет таких шагов.

## Что нужно

- QGIS 4.0 или новее.
- Языковая модель: любой OpenAI-совместимый эндпоинт или Anthropic API.
  Локальным серверам вроде Ollama и LM Studio ключ не нужен.

Всё, что читает агент, уходит в выбранную модель. Прочитайте
[«Данные и конфиденциальность»](privacy.md), прежде чем подключать удалённого
провайдера.

Начните с [установки](SETUP.md), затем посмотрите
[использование](usage.md). Интерфейс на английском и русском и следует за
языком QGIS.
