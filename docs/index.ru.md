# QGIS AI Agent

ИИ-агент внутри QGIS 4: изучает проект и обрабатывает данные по запросу на
естественном языке. Работает циклом — смотрит на проект, вызывает инструменты,
видит результаты, решает следующий шаг. Изменения применяются только после
вашего подтверждения.

## Что умеет

Пять доменов, 25 инструментов:

| Домен | Примеры запросов |
| --- | --- |
| `inspect` | «какие у меня слои?», «какие значения в поле highway?» |
| `project` | «загрузи файл», «спрячь слой», «сохрани проект» |
| `style` | «сделай реки синими», «раскрась по населению», «подпиши названиями» |
| `processing` | «построй буфер 500 м», «обрежь по границе района», «посчитай NDVI» |
| `osm` | «скачай кафе в Твери», «дороги кроме грунтовых из OSM» |

## Модель безопасности

Агент никогда не меняет проект без присмотра:

- **Читающие** инструменты (список слоёв, описание полей, запросы к данным)
  выполняются сразу — они ничего не могут изменить.
- **Пишущие** инструменты (оформление, обработка, загрузка данных) копятся в
  карточку плана. Ничего не выполняется, пока вы не нажмёте **Применить**;
  **Отменить** сбрасывает весь батч.

Аргументы проверяются при постановке в очередь, пока агент ещё слушает: буфер
в метрах на слое в градусах отклоняется с готовым планом перепроецирования, а
не превращается в мусор.

## Что нужно

- **QGIS 4.0 или новее.**
- **Аккаунт и ключ API** у провайдера языковых моделей — любой
  OpenAI-совместимый эндпоинт или Anthropic. Локальным серверам (Ollama,
  LM Studio) ключ не нужен вовсе.
- Ваши запросы и краткие сводки о проекте — имена слоёв, полей, CRS —
  отправляются выбранному провайдеру, поэтому выбирайте того, кому доверяете.
  Ключ хранится в системном хранилище, а не в проекте и не в настройках.

Готовы попробовать? Начните с [установки](SETUP.md), затем посмотрите
[примеры запросов](usage.md).

## Интерфейс

Доступен на английском и русском, следует за языком интерфейса QGIS. Сам агент
отвечает на том языке, на котором вы к нему обращаетесь.
