# Использование

Откройте панель через пункт меню **AI Agent** или значок на панели
инструментов, наберите запрос, нажмите Enter. Shift+Enter переносит строку;
пока агент работает, кнопка отправки превращается в «стоп».

## Вопросы о проекте

Чтение выполняется сразу, без подтверждения:

- *какие у меня слои?*
- *какие поля у слоя дорог и что лежит в `highway`?*
- *сколько дорог типа motorway?*
- *какая река самая длинная?* — длина и площадь берутся из самой геометрии;
  отдельная колонка с длиной не нужна
- *почему города красные?* — агент читает настоящий рендерер, а не угадывает

## Изменения

Запись копится в карточку плана; **Применить** выполняет её, **Отменить**
сбрасывает:

- *сделай реки синими* / *дороги — тонкие серые пунктирные линии*
- *раскрась районы по населению, 7 классов, Viridis*
- *подпиши города названиями, жирным, 12 пунктов, с белой обводкой* — один
  шаг, а не четыре
- *построй буфер 500 м вокруг школ* — на слое в градусах агент сам сначала
  перепроецирует
- *загрузи /data/roads.geojson в группу «Фон»*
- *скачай кафе в Твери из OSM* / *дороги кроме грунтовых в текущем виде*
- *обрежь дороги по границе города, посчитай длину и сохрани проект* — целая
  цепочка ложится в одну карточку плана

## Диалоги

Диалоги переживают перезапуск QGIS и привязаны к проекту: меню **Диалоги**
показывает только начатые в открытом сейчас проекте. Заголовок — ваша первая
реплика. Восстановление диалога возвращает и контекст модели: уточнение вроде
*а сколько их?* продолжает работать.

## Когда что-то идёт не так

- Ошибка инструмента не убивает прогон: агент читает её и исправляется сам —
  на неверное имя слоя он получает список настоящих.
- Кнопка «стоп» немедленно прерывает прогон и сбрасывает запланированные
  изменения.
- Overpass (сервис OSM) публичный и бывает занят; отказ — не поломка плагина:
  повторите позже или сузьте запрос.
- Маленькая локальная модель (7–8B) будет путаться в вызовах. Осмысленный
  минимум — модель уровня 30B с поддержкой function calling.
