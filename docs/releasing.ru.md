# Выпуск версии

Выпуск — одна кнопка в GitHub. Сценарий `.github/workflows/release.yml`
прогоняет тесты, собирает zip, загружает его на
[plugins.qgis.org](https://plugins.qgis.org/plugins/ai_agent/) и только после
этого ставит тег и публикует GitHub-релиз с приложенным zip.

## Однократная настройка

1. На plugins.qgis.org откройте **AI Agent → Tokens**
   (`https://plugins.qgis.org/plugins/ai_agent/tokens/`) и создайте токен.
2. В репозитории GitHub откройте **Settings → Secrets and variables → Actions**
   и добавьте его как секрет `QGIS_PLUGIN_TOKEN`.

Токен читается только из этого секрета и никогда не попадает ни в код, ни в
логи.

## Каждый выпуск

1. Поднимите `version=` в `ai_agent/metadata.txt` и `version` в
   `pyproject.toml`, добавьте запись в начало `changelog=` — версия отдельной
   строкой с отступом, затем пункты с `- `. Все строки changelog должны быть с
   отступом: строка без отступа делает метаданные нечитаемыми для каталога
   плагинов.
2. Смержите это в `main`.
3. **Actions → release → Run workflow** на `main`.

Сценарий падает до публикации, если не прошли тесты, если тег этой версии уже
существует или если в changelog нет записи для неё. Если plugins.qgis.org
отклонил загрузку, тег не ставится — исправьте причину и запустите снова.
`python3 tools/release_notes.py` печатает текст, который попадёт в релиз.

Новая версия появляется на plugins.qgis.org после автоматических проверок и,
для аккаунтов без роли одобряющего, ручного одобрения волонтёрами каталога.
