# Метрики

plugins.qgis.org считает скачивания каждой версии, GitHub — посещения
репозитория. Ни тот, ни другой не хранят историю: страница плагина показывает
накопленные итоги, а GitHub забывает посещения через 14 дней. Динамику
сохраняет ежедневный снимок. Собственные анонимные счётчики плагина — другое
дело, они описаны на странице [статистики использования](usage-stats.md).

## Ежедневный снимок

Workflow `metrics` запускается раз в день и вручную со вкладки Actions.
`tools/collect_metrics.py` дописывает числа за день в ветку `metrics`:

- `downloads.csv`: накопленные скачивания каждой версии по дням;
- `traffic.csv`: просмотры, клоны и уникальные посетители по дням;
- `daily_downloads.svg`: новые скачивания за день;
- `README.md`: итоги по версиям, последние две недели и график.

В скачивания входят обновления, поэтому первые дни после выпуска примерно
показывают, сколько установок в ходу.

## Настройки

Скачиваниям ничего не нужно. Посещениям нужен fine-grained token для этого
репозитория с **Administration: read**, сохранённый как секрет
`METRICS_TOKEN`. Без него прогон собирает только скачивания, как и когда
GitHub не ответил. Если plugins.qgis.org не вернул список версий, прогон падает
и ничего не сохраняет.
